# 铁花 · 独立纯前端版

独立于 `tiehua-game/` 与 Cocos 的浏览器小游戏。无需微信 AppID、游戏引擎、后端、数据库或第三方运行时依赖。没有修改原微信小游戏工程。

## 本地试玩

需要 Node.js 18+，不需要 `npm install`：

```bash
git clone https://github.com/gingobeer/tiehua-web.git
cd tiehua-web
npm run dev
```

打开 **http://127.0.0.1:4180**。不要直接双击 `index.html`：ES Modules 需要 HTTP 静态服务。

Node.js 仅用于本地预览、测试和拷贝发布文件，不是线上业务后端。

手机局域网测试可运行：

```bash
HOST=0.0.0.0 PORT=4180 npm run dev
```

然后在同一网络的手机上打开 `http://电脑局域网IP:4180`。该命令会开放局域网访问，请仅在可信网络使用。当前默认服务只监听本机。

## 操作

在「这一击的分量」面板先选「轻松体验」或「拟真挑战」，默认轻松，记住上次选择。下述流程为轻松档。

1. 点击「开炉打铁花」。
2. 在画布左下方炉口按住约0.2秒，等待装载量增长。
3. 向上提一点再松开，稍停后松手也会辅助抛出。
4. **重新按下**，向上划过铁水周围的虚线圈，圈内即可命中。
5. 等待下一勺，重复操作。默认一炉60秒。

- 「慢慢练，不计时」：在开炉前开启，自由练习。
- 「先看一场铁花」：自动演示，不计入个人成绩。
- 轻击/重击、方向、接触准确度和装载量都会改变成花。
- 键盘辅助：`1` 装载，`2` 上抛，`3` 自动瞄准击打，`Shift+3` 重击。不是手势物理输入，用于无障碍体验和流程测试。
- `P` 暂停/继续；失焦、切后台和打开帮助也会暂停，回来后需要手动继续。
- 声音默认关闭，右上角开启；全屏能力以浏览器支持情况为准。
- 最高分仅存储于当前浏览器的 localStorage，禁用存储时仍可玩。

### 难度切换

| 参数 | 轻松体验 | 拟真挑战 |
| --- | --- | --- |
| 舀取速率 / 最低装载 | 3.0/s / 10% | 1.9/s / 16% |
| 上提距离 | 画布高度3.5% | 画布高度5.5% |
| 松手要求 | 上提后停住也可，最低5.2m/s辅助上抛 | 向上速度至少0.8m/s，无最低上抛辅助 |
| 命中半径 | 画布9.5% | 画布5% |
| 待击飞行 | 0.65倍速 | 正常速度 |

游戏中选择另一档不会立即改变当前物理；点击「切换并重新开炉」才生效并清空本炉，选回原档可取消。两档均支持不计时练习。虚线圈、提示和顶部难度标签同步。

两档最高分按 `tiehua-web-best-v2-easy` / `tiehua-web-best-v2-realistic` 分开保存。旧版不区分难度的纪录保留在旧键中，不混入新榜；使用键盘辅助的回合仍显示得分，但不更新最高分。拟真仅是减少操作辅助，仍有命中容错、速度限幅和二维近似，并非实验校准的真实模拟。

## 架构

```text
index.html             页面、操作引导、仪表、菜单
styles.css             桌面/手机布局、全屏样式
src/
  physics.js           独立模型、状态机、粒子、回合计分
  input.js             Pointer Events + 近期速度采样
  renderer.js          Canvas 2D 场景、人物剪影、铁花光迹
  audio.js             Web Audio 程序化击打声
  app.js               UI、生命周期、输入与模型连接
scripts/
  serve.mjs            本地静态文件预览
  build.mjs            生成 dist/，无需打包器
  browser-check.mjs    可选 Playwright 浏览器回归
test/
  physics.test.mjs     Node 内置测试
```

物理计算采用固定1/120秒步长。Pointer Events 统一鼠标与触摸；速度在游戏世界尺度下计算，不依赖屏幕像素。命中按最新移动线段判断，而不是最后松开时的起终点连线。触摸取消与失焦不会触发击打。

全部背景、人物剪影、火星和音效由本地代码生成；没有远程字体、图片、音频、CDN脚本、分析埋点或网络账号请求。人物目前是程序化剪影，不是写实骨骼动画。

## 物理边界

这不是真实冶金仿真或操作训练：

- 二维粒子近似，重力、球形空气阻力、对流/辐射冷却、有效相变温区。
- 发射质量归一化，粒径由质量反推，动能受可用碰撞能量预算约束。
- 成花主要发生在击打时，不做定时空中二次爆炸。
- 碰撞传递效率、接触半径、液滴分布、工具等效质量为交互假设。
- 易上手参数集中在 `physics.js` 的 `ASSIST`：舀取速率3.0/s、最低装载10%、最低上提距离为画布高度3.5%、命中半径9.5%、最低划击速度0.25m/s。
- 上抛有5.2m/s的最低向上辅助速度，并限制横漂与释放位置；待击铁水以0.65倍模拟速度飞行，提供更长反应窗口。回合倒计时和成花后粒子保持正常速度。这是游戏辅助，不是现实物理。
- UI「力度%」是有效碰撞能量归一化后的游戏指标，不是手机压力传感器测量。
- 未模拟不可压缩液体、氧化壳、碳燃烧分枝、三维碰撞或真实人体动作。
- 暖色光迹是短曝光艺术映射，不是光谱标定。
- 自动降低光晕及显示粒子密度只影响渲染，不在低画质时删除物理质量。
- 计分奖励有效命中和冲击强度，最高花高是诊断统计，不是仪器测量。

工艺参考：
- [国家非遗数字博物馆：确山打铁花](https://www.ihchina.cn/project_details/15214)
- [国家非遗数字博物馆：蔚县打树花](https://www.ihchina.cn/project_details/23893.html)

这两种工艺并不相同。本作借用“舀取—上抛—挥击”的游戏化动作，未实现花棚或墙面碰撞。现实中打铁花危险，请勿模仿。

## 测试

```bash
npm test
npm run build
```

15项单元/回归测试包含：装载、辅助上抛、放宽命中/远处挥空、待击窗口、质量和能量预算、方向/力度、不同帧率、冷却、计时、回收、速度窗口、延迟抬手、双难度差异及切换重置。

浏览器回归使用可选 Playwright 环境（不是游戏依赖）：

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/browser-check.mjs
```

也可以指定已有测试工具与浏览器：

```bash
PLAYWRIGHT_PATH=/path/to/playwright \
CHROME_PATH="/path/to/chrome" \
node scripts/browser-check.mjs
```

运行前执行 `npm run build` 并启动4180端口的本地服务。默认使用本地安装的 Playwright 及其 Chromium，也可以通过上述环境变量指定工具路径。

浏览器验收覆盖：桌面鼠标完整动作链、手机视口触摸完整动作链、暂停恢复、键盘辅助、帮助弹窗、触摸取消、演示和玩家回合分离。输出截图与结果在 `artifacts/`。

已用本机 Chrome 无头模式验证桌面及390px手机触摸模拟，未做真实 iPhone Safari、微信内置浏览器及低端手机性能验收，不能把模拟器测试当作真机通过。

## 发布为网站

```bash
npm run build
```

将 `dist/` 全部内容上传到静态托管服务（例如对象存储+CDN、GitHub Pages、Cloudflare Pages、Netlify）。使用HTTPS，确保 `.js` 为JavaScript MIME类型；资源均为相对路径，可部署在子目录。

构建结果仅包含HTML/CSS/JS，不包含测试工具、截图或本地服务。不依赖微信登录或 AppID。

### GitHub Pages

在线入口：**https://gingobeer.github.io/tiehua-web/**

仓库 Settings → Pages 的 Source 使用 **Deploy from a branch**，分支 **main**，目录 **/ (root)**。本项目使用原生 ES Modules，根目录的入口和 `src/` 即可直接运行，无需编译。

推送到 `main` 后由 GitHub 内置 Pages 流程自动发布；`_config.yml` 排除说明文档、测试与开发脚本。发布前请运行 `npm test`，当前分支发布方式不会自动执行项目测试。`npm run build` 仍用于生成可供其他静态托管服务使用的 `dist/`。

部署状态可在 Actions 的 `pages build and deployment` 查看。无需额外服务器、工作流权限或自定义令牌。
